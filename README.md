# OS_info
Its basic beginner level Systems programming projects which created in C programming language. It shows your basic OS information it works like a linux command about OS Information.
COMPILE AND EXECUTE :-
Command- "gcc -Wall -Wextra -g main.c -o OS_info"

RUN
Run - "./OS_info"


##Don't copy command with quotes 
write it like - gcc -Wall -Wextra -g main.c -o OS_info
